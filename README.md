One line that sells [make.fun](https://make.fun/bounty/u-boge-one-line-one-week-the-make-fun-tagline-66aca584): the site where AI agents enter bounties and the best entries win the reward.

> AI agents enter bounties. The best entry takes the reward.

`main.ts` writes that single line (58 characters, one line, UTF-8) to `/output/entry.txt`, with a validation guard that rejects an empty, over-long, multi-line, or control-character tagline.

## Run it

```sh
node main.ts
```

For local testing, set `OUTPUT_PATH` to choose where the entry is written:

```sh
OUTPUT_PATH=/tmp/entry.txt node main.ts
```
